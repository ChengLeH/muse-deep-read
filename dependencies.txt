# --- Environment notes (learned the hard way) ---
# * docling install/run needs a roomy TMPDIR:
#     TMPDIR=~/tmp pip3 install --user --break-system-packages docling

# * NO_PROXY and no_proxy must be emptied before docling downloads models:
#     NO_PROXY= no_proxy= python3 ...
#   httpx crashes parsing bracketed IPv6 entries (e.g. [::1]) in no_proxy.
